DIWALI FARAL ORDER WEBSITE

Files:
- index.html: website content
- style.css: styling and mobile layout
- script.js: menu, half-kg/1-kg pricing, cart and WhatsApp order message
- images/: the 11 images supplied for the products

WhatsApp number:
9158448613 (international link uses country code 91)

How to test:
1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, or Firefox.
3. Choose ½ kg or 1 kg for any item and click Add.
4. Add multiple items if needed.
5. Fill in name and phone number.
6. Click "Send order on WhatsApp".
7. WhatsApp opens with the order filled in. The customer must press Send.

Important:
- This is a static website; it does not require Java, a database, or a local server.
- The customer must have WhatsApp or WhatsApp Web available to send the message.
- Orders are not sent silently; the customer confirms by pressing Send.
- Images are the ones supplied with the request and are bundled locally in the images folder.
- To publish a public link, upload the extracted folder to a static host such as GitHub Pages or Netlify. Keep index.html at the root.
